# 颜见小程序开源版
## 项目简介
《颜见小程序》是一款以用户申请微信，解锁聊天为主要模式的社交软件，基于微信小程序原生开发
## 快速启动
### 前置条件
  - `project.config.json`修改为自己的appId
  - `env.js`修改相关服务端配置，其中baseURL是服务端接口地址，为启动必要配置，请先确保服务端成功启动
  - 从微信后台加为此小程序的开发者
  - 本地调试请勾选微信开发者工具不校验合法域名，否则接口无法请求，具体步骤：详情-不校验合法域名
### 启动步骤
1. 导入到微信开发者工具中打开
2. `npm install`下载依赖
3. 微信开发者工具中 => 工具 => 构建npm
4. 然后重新编译
